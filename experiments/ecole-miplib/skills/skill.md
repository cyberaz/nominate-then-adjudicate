# SCIP 参数调优经验：10 选 1 选择任务专用（按问题类型分节）

> 由多批已解实例的 EPM Top-10 候选 + 真实 10 选 1 后果迭代总结而来。
> 用途：从 EPM 提名的 10 个候选中 10 选 1。唯一目标：选出**实际最快**的那个，
> 即追求最高加速比。

---
## set_covering

### 1. 否决规则
- **禁止双重聚合（9与722除外）**：当 `presolving/donotaggr = False` 且 `presolving/donotmultaggr = False` 时，原则上排除（如 292, 190, 488, 743）。Set Covering 的 `>=1` 约束与全1系数矩阵不适合等式代换，易破坏矩阵结构。**例外：配置 9 和 722 已验证在中等密度实例中表现优异（如 seed 25, 30 中斩获 12x+ 加速比），正式解禁。**
- **禁止完全关闭预求解**：当 `presolving/maxrounds = 0` 时排除（如 900）。在大规模实例中缺失预求解是致命的。
- **禁止关闭传播**：当 `propagating/maxrounds = 0` 时排除（如 737, 658, 678, 399, 545）。传播缺失导致边界收紧失败。
- **警惕过度启发式（观察中，不再降级）**：若 `heuristics/undercover/freq >= 50` 且 `heuristics/alns/freq >= 50`（如 368），原认为在根节点易解实例中引入纯开销，但 seed 22, 23 中 368 均作为 Oracle 表现优异，故取消降级，正常参与竞争。

### 2. 实例级条件化规则
- **极稀疏矩阵 (`matrix_density < 0.05`)**：优先选 **533** 或 **351**。若无，则寻找满足 `separating/clique/freq >= 20` 且 `heuristics/feaspump/freq = -1` 的配置（如 62）。此类实例 LP 松弛较弱，需依赖高频 Clique 割平面并关闭 Feasibility Pump。
- **极稠密且超定系统 (`matrix_density > 0.12` 且 `row_count > col_count`)**：优先选 **785**。需开启根节点割平面轮数（`separating/maxroundsroot = 10`）并放宽正交性阈值（`cutselection/hybrid/minortho = 0.1`）以快速收紧边界。
- **中等密度 (`0.05 < density < 0.15`)**：绝对优先选 **62**。若 62 不在，优先选 **685, 82, 567**（新晋 Oracle 专业户，均开启 `donotmultaggr=T` 且 clique 频率适中），其次才是 **907, 706**。

### 3. 安全取值 / 编号画像
- **62**：**根节点杀手**。`donotmultaggr=T`, `clique/freq=20`, `feaspump=-1`。在中等及偏稀疏密度实例中表现统治级，只要候选中有且实例非极端稠密，应作为无脑首选。
- **685 / 82 / 567**：**中等密度新晋杀手**。685 (`clique=10`, `feaspump=-1`), 82 (`clique=5`, `alns=-1`), 567 (`clique=20`, `alns=50`)。在 62 缺席时，它们多次斩获 Oracle（seed 23, 25, 26, 28, 30），优先级高于 907/706。
- **907 / 706**：**中等密度强力备选**。均禁止聚合（`donotaggr=T`），706 依赖 Zero-half 割平面，907 依赖 Zero-half 且关闭 Gomory。当 62/685/82/567 均不在时作为兜底。
- **9 / 722**：**解禁的双重聚合特例**。在 seed 25, 30 中表现优异（12x+），不再被双重聚合规则误杀，可作为常规候选。
- **533 / 351**：**稀疏矩阵专家**。在 `density < 0.05` 时表现最佳。
- **785**：**稠密超定专家**。专治 `rows > cols` 且高密度的硬骨头。

### 4. 10 选 1 checklist
1. **算密度与维度**：提取 `matrix_density`、`row_count`、`col_count`。
2. **排雷**：直接划掉 `donotaggr=F` 且 `donotmultaggr=F` 的配置（**9 和 722 除外**），以及 `maxrounds=0`（900）或 `propagating/maxrounds=0`（737等）的配置。不再降级 368 等高频启发式配置。
3. **稀疏分支**：若 `density < 0.05`，在剩余候选找 **533**、**351** 或 **62**；若无，找 `clique/freq >= 20` 且 `feaspump = -1` 的配置。
4. **稠密超定分支**：若 `density > 0.12` 且 `rows > cols`，首选 **785**；若无，找 `maxroundsroot > 0` 且 `minortho <= 0.1` 的配置。
5. **常规/中等密度**：首选 **62**。若 62 不在，优先选 **685, 82, 567**，其次选 **907, 706**，最后考虑 **9, 722**。
6. **决胜微调**：不要陷入“唯禁止聚合论”。允许单重聚合（`donotaggr=F` 但 `donotmultaggr=T`）的配置（如 685, 82）在中等密度下往往比完全禁止聚合的配置更快，若剩余候选中有 685/82/567，直接选之。

## facility_location

### 1. 否决规则
- **条件否决 11**：在纯二进制实例表现差。**当 `binary_ratio == 1.0` 时，必须排除 11**。
- **条件否决 440 (观察中)**：在大规模 MIP 下表现不稳定。**当 `row_count > 1500` 且为混合整数时，原则上排除 440**。
- **条件否决 941 (观察中)**：在纯二进制下存在严重翻车风险（如 seed 27 仅 0.17x 远慢于默认）。**当 `binary_ratio == 1.0` 时，原则上排除 941**。

### 2. 实例级条件化规则
- **纯二进制结构 (`binary_ratio == 1.0`)**：优先选 **180** 或 **84 (观察中)**。若两者不在或排名靠后，**强烈偏好 `presolving/maxrounds = 0` 且 `presolving/donotmultaggr = True` 的配置**（此类配置在纯二进制下剪枝极快），但需警惕 941 等方差极大的配置。
- **大规模混合整数 (`row_count > 1500` 且 `binary_ratio < 0.1`)**：首选 **180**。若 180 不在，**965** 和 **313 (观察中)** 是极佳的替代，其根节点割平面与传播能有效收紧大规模边界。
- **中小规模混合整数 (`row_count < 1500` 且 `binary_ratio < 0.1`)**：此区间 **11** 是绝对王者（seed 21/26/30 均斩获极高加速比）。优先选择 **`presolving/maxrounds = 0`** 的候选（如 11, 900, 965, 413），并结合 EPM 排名选最高者。若 11 不在，**900 (待验证)** 和 **965** 是极佳的强力替代。

### 3. 安全取值 / 编号画像
- **11 (中小MIP杀手)**：关闭预求解与聚合 (`presolving/maxrounds=0`, `donotmultaggr=True`)。在中小 MIP 极快 (seed 21/26/30)，但在纯二进制下翻车。
- **180 (全能王)**：关闭预求解，高频 Feaspump，开启 Conflict。在纯二进制下最为稳健 (seed 25/27 均稳超默认)，无翻车记录。
- **965 (根节点割平面利器)**：`separating/maxroundsroot=5` 与 `cutselection/ensemble/maxnonzerorootround=20.0`。在 facility_location 结构下能有效收紧边界 (seed 24 斩获 10.6x)，应作为常规强力候选。
- **900 (中小MIP奇兵，待验证)**：`presolving/maxrounds=0`, `donotmultaggr=True`, `gomory=5`, `maxnonzerorootround=8.0`。在中小 MIP 下爆发力极强 (seed 28 14.6x, seed 30 4.7x)。
- **440 / 313 (奇兵组)**：440 在中小 MIP 爆发 (seed 17) 及纯二进制偶有高光 (seed 27)；313 在大规模 MIP 亦有高光 (seed 16，观察中)。
- **84 (纯二进制备选，观察中)**：在部分纯二进制实例中表现平庸 (seed 15)，需结合 `maxrounds=0` 特征综合判断，不再盲目迷信。
- **941 (纯二进制高危，观察中)**：在纯二进制下方差极大 (seed 22 5.2x vs seed 27 0.17x 严重翻车)，需严格限制使用。

### 4. 10 选 1 checklist
1. **看变量类型**：若 `binary_ratio == 1.0`（纯二进制），优先 **180, 84**；若不在，寻找 `presolving/maxrounds = 0` 且 `donotmultaggr = True` 的配置。划掉 11、941。
2. **看矩阵规模**：若 `row_count > 1500`（大规模 MIP），首选 **180**，次选 **965, 313**。划掉 440。
3. **中小规模 MIP 筛选**：若 `row_count < 1500` 且 `binary_ratio < 0.1`：
   - 第一步：从 10 个候选中筛出 `presolving/maxrounds = 0` 的配置（如 11, 900, 965, 413, 772）。
   - 第二步：在筛选出的配置中，选择 **EPM 排名最高** 的一个。若 11 在列且排名前三，可直接锁定 11；若 11 不在，重点关注 **900** 和 **965**。

## independent_set

### 1. 否决与降级规则
- **降级警惕 942**：在多次作为中等密度/稀疏图兜底选择时均未夺冠且加速比平庸。仅在无更好选择时使用，不作为首选兜底。
- **参数级警惕**：警惕同时开启 `conflict/enable = True` 且 `presolving/maxrounds = -1` 与 `propagating/maxrounds = -1` 的配置，在独立集问题上易产生纯开销。

### 2. 实例级条件化规则
- **高密度小图（`matrix_density > 0.03` 且 `col_count <= 80`）**：优先选 **273**。此类图结构紧凑，273 的极少预求解（5轮）和关闭 clique 割能避免无效开销。
- **中等密度中等图（`0.015 <= matrix_density <= 0.028` 且 `70 <= col_count <= 120`）**：优先选 **67**。若 67 不在，**强烈优先选 719、99 或 627**。**严禁使用 942 兜底**。
- **稀疏中大图（`0.008 <= matrix_density < 0.015` 且 `row_count > 800`）**：优先选 **729** 或 **627**。此区间 599/99 表现平庸，729（关传播）与 627（开冲突、深预求解）在此结构下多次夺冠（如 seed=22, 25, 27, 30）。
- **极稀疏大图（`matrix_density < 0.01` 且 `row_count > 1000`）**：优先选 **926**。若 926 不在，**优先选 599、99 或 719**。
- **列极稀疏图（`mean_nonzeros_per_col < 6.0`）**：优先选 **642**（观察中：若 599/719 同在可优先考虑，因 seed=21 中 599 优于 642）。保留完整传播但限制预求解（10轮）是其核心逻辑。

### 3. 安全取值 / 编号画像
- **719 / 99 / 599 (新晋主力)**：核心画像是**关闭冲突分析 (`conflict/enable = False`)**，这在独立集问题上能大幅减少无效开销，加速比极高。
- **627 (稳健主力)**：开启预求解(20轮)和传播(50轮)，在中等/稀疏图上表现极其稳定，是极佳的稳健选择。
- **729 / 785 (稀疏图奇兵)**：729（关冲突、关传播、预求解-1）与 785（开冲突、传播-1、预求解20）在 `0.008 <= density < 0.015` 的稀疏图中具有统治力。
- **114 / 415 (强力替补)**：偏向中等偏大图，可作为特征不匹配时的优选。
- **67 (旧主力)**：核心画像是“关传播、关奇环割、开冲突分析”，若出现仍优先选择。

### 4. 10 选 1 checklist
拿到 10 个候选编号后，按以下顺序执行：
1. **匹配密度与规模**：
   - 若 `matrix_density > 0.03` 且 `col_count <= 80` $\rightarrow$ 锁定 **273**。
   - 若 `0.015 <= matrix_density <= 0.028` 且 `70 <= col_count <= 120` $\rightarrow$ 锁定 **67**；若不在，优先锁定 **719, 99, 627**。
   - 若 `0.008 <= matrix_density < 0.015` 且 `row_count > 800` $\rightarrow$ 锁定 **729** 或 **627**。
2. **匹配稀疏度特征**（若步骤1未命中）：
   - 若 `matrix_density < 0.01` 且 `row_count > 1000` $\rightarrow$ 锁定 **926**；若不在，优先锁定 **599, 99, 719**。
   - 若 `mean_nonzeros_per_col < 6.0` $\rightarrow$ 锁定 **642**（若 599/719 同在可优先）。
3. **参数级优选**（若上述编号均不在）：
   - 优先选择 **`conflict/enable = False`** 的配置。
   - 在剩余候选中选择 **114, 415, 627**。
4. **兜底选择**：若以上均未命中，选 EPM 排名第 1 的编号。**尽量避免 942**，除非它是唯一选择。

## combinatorial_auction

### 1. 否决规则
- **绝对黑名单**：直接排除编号 **413, 76, 963, 488**。它们在部分实例中实测劣于默认（加速比 < 1.0x）。
- **参数级否决**：若候选配置中 `heuristics/dins/minfixingrate >= 0.7` 且 `presolving/maxrounds = 0`（如 413），或 `propagating/maxrounds = 0` 且 `heuristics/undercover/freq = 0`（如 963），直接排除。组合拍卖（本质为集合包装问题）需要基础传播和启发式支撑，完全切断会导致搜索盲目。

### 2. 实例级条件化规则
- **稀疏/窄列规则**：当 `matrix_density < 0.03` 且 `mean_nonzeros_per_col < 5.0` 时（如 seed=21, 22），首选 **274**（实测 15.11x, 8.34x）。此类实例变量冲突少，274 关闭 FeasPump/ALNS，将算力全倾注于根节点传播与对偶单纯形，能极速收紧边界。
  - **274 缺席时的稀疏兜底**：若 274 不在候选中，优先考察 **743**（如 seed=24, 7.28x）、**709** 或 **767**（在 seed=21, 24, 30 中多次取得 8x-16x 的爆发加速，待验证）。**368** 在部分实例（如 seed=23, 1.07x）表现平庸，降级为备选（观察中）。
- **宽行规则**：当 `mean_nonzeros_per_row > 15` 时（如 seed=26, 27, 30），优先选 **743**（强分支在宽行下表现极佳，如 seed=30 10.03x）或 **722**（如 seed=27 9.65x）。宽行实例约束极宽，743 的 Fullstrong 强分支与 722 的 Clique 割平面能高效剪枝。**479**（关闭预求解）在宽行下并非唯一解，有时不如 743/722（如 seed=26），作为宽行备选（观察中）。
- **中等密度规则**：当 `0.03 <= matrix_density <= 0.08` 且非宽行时（如 seed=25, 28, 29），首选 **722**。其开启高频 Clique 割平面并限制预求解轮数，完美契合集合包装的冲突图结构，表现极其稳健。

### 3. 安全取值 / 编号画像
- **274 (稀疏/窄列首选主力)**：根节点传播极强，关闭冗余启发式。在稀疏/窄列密度下表现统治级（如 seed=21 15.11x），从未劣于默认。
- **722 (中等密度/宽行稳健王)**：开启 Clique 割平面（`freq=10`）并限制预求解轮数（`maxrounds=10`）。不仅在中等密度（如 seed=25, 28, 29）稳健，在宽行实例（如 seed=22 10.60x, seed=27 9.65x）也极具统治力，适用性极广。
- **743 (宽行/硬实例杀手)**：关闭 Clique/Gomory，限制传播，依赖 Fullstrong 强分支（`maxdepth=20`）。在宽行（如 seed=26, 30）和稀疏兜底（如 seed=24）中均取得极高加速比，是宽行结构的首选。
- **709 / 767 (高加速比奇兵)**：在多个实例（seed=21, 24, 30）中作为事后最优（Oracle）取得 8x-16x 的惊人加速，若候选中出现且特征匹配（稀疏/宽行），应高度重视（待验证）。
- **479 (预求解关闭特化)**：在部分高密度/宽行矩阵中有效，但在宽行下并非总是最优（如 seed=26 逊于 743），适用性需进一步观察（观察中）。
- **368 (稀疏结构奇兵)**：开启大量启发式与 5000 轮根节点传播。在部分稀疏实例中表现平庸（如 seed=23 仅 1.07x），优先级降低（观察中）。

### 4. 10 选 1 checklist
1. **清洗**：从 10 个候选中直接剔除黑名单（413, 76, 963, 488）及触发参数级否决的配置。
2. **看稀疏度与列宽**：检查 `matrix_density` 和 `mean_nonzeros_per_col`。若密度 < 0.03 且列均非零元 < 5.0，直接锁定 **274**。若 274 缺席，优先在候选中寻找 **743**、**709** 或 **767**。
3. **看行宽**：检查 `mean_nonzeros_per_row`。若行均非零元 > 15，优先锁定 **743** 或 **722**；若均缺席，再考虑 **479**。
4. **中等密度兜底**：若上述特征均不满足（中等密度/常规结构），优先选择 **722**；若候选中无 722，则选 **743**（强分支兜底）。
